页面：http://127.0.0.1:8082/

底盘主体及平台采用占用网格规则布球；body_base_link 按高度分区。双臂采用显式手写球心模板，半径按原始网格顶点及表面采样初始化并向上量化，仍需人工调整。右臂单独评估。轮子、头部、相机、夹爪保留原模型。

## 使用

选择“编辑 link”和“球编号”，修改 X/Y/Z 与半径（单位米）；点击“检查此 link 表面覆盖”；点击“保存为新候选配置”生成带时间戳的 YAML。查看 link 仅过滤球，不隐藏其他机器人网格。双臂/升降滑块只用于显示，保存配置时不保存检查姿态。
